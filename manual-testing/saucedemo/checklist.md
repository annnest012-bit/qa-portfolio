# Чек-лист тестирования saucedemo.com

## Авторизация
- [ ] Вход с валидными данными (standard_user)
- [ ] Вход с заблокированным пользователем (locked_out_user)
- [ ] Вход с невалидным паролем
- [ ] Вход с пустыми полями
- [ ] Вход с пустым логином
- [ ] Вход с пустым паролем
- [ ] Проверка чувствительности к регистру логина
- [ ] Проверка чувствительности к регистру пароля

## Каталог товаров
- [ ] Отображение всех товаров
- [ ] Сортировка по имени (A-Z)
- [ ] Сортировка по имени (Z-A)
- [ ] Сортировка по цене (Low to High)
- [ ] Сортировка по цене (High to Low)
- [ ] Переход на страницу товара
- [ ] Добавление товара в корзину
- [ ] Удаление товара из корзины
- [ ] Счетчик товаров в корзине

## Корзина
- [ ] Отображение добавленных товаров
- [ ] Удаление товара из корзины
- [ ] Переход к оформлению заказа
- [ ] Возврат к покупкам

## Оформление заказа
- [ ] Ввод имени, фамилии, индекса
- [ ] Проверка обязательности полей
- [ ] Отображение итоговой суммы
- [ ] Завершение заказа
- [ ] Возврат на главную после заказа
