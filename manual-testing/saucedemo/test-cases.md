# Тест-кейсы для saucedemo.com

## TC-001: Вход с валидными данными
**Предусловие:** Пользователь находится на странице входа
**Шаги:**
1. Ввести `standard_user` в поле "Username"
2. Ввести `secret_sauce` в поле "Password"
3. Нажать кнопку "Login"
**Ожидаемый результат:** Пользователь перенаправлен на страницу каталога товаров

## TC-002: Вход с заблокированным пользователем
**Предусловие:** Пользователь находится на странице входа
**Шаги:**
1. Ввести `locked_out_user` в поле "Username"
2. Ввести `secret_sauce` в поле "Password"
3. Нажать кнопку "Login"
**Ожидаемый результат:** Появляется сообщение об ошибке "Sorry, this user has been locked out."

## TC-003: Вход с невалидным паролем
**Предусловие:** Пользователь находится на странице входа
**Шаги:**
1. Ввести `standard_user` в поле "Username"
2. Ввести `wrong_password` в поле "Password"
3. Нажать кнопку "Login"
**Ожидаемый результат:** Появляется сообщение об ошибке "Username and password do not match"

## TC-004: Добавление товара в корзину
**Предусловие:** Пользователь авторизован, находится на странице каталога
**Шаги:**
1. Нажать кнопку "Add to cart" на карточке товара "Sauce Labs Backpack"
**Ожидаемый результат:** 
- Кнопка меняется на "Remove"
- Счетчик корзины увеличивается на 1
- Товар отображается в корзине

## TC-005: Удаление товара из корзины
**Предусловие:** Пользователь авторизован, товар добавлен в корзину
**Шаги:**
1. Нажать кнопку "Remove" на карточке товара
**Ожидаемый результат:** 
- Кнопка меняется на "Add to cart"
- Счетчик корзины уменьшается на 1
- Товар исчезает из корзины
